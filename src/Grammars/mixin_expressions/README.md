# HELIX Mixin Expressions

TextMate syntax-highlighting bundle for standalone HELIX mixin expression files with the
`.hxmixin` extension.

In a JetBrains IDE, open **Settings | Editor | TextMate Bundles**, add the `mixin_expressions` directory,
and apply the settings. Its `package.json` registers the language and points JetBrains at the JSON
grammar in `syntaxes/`.

That grammar is the canonical source used by the HELIX documentation site.
