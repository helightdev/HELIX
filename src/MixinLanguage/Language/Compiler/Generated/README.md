# Generated Hix grammar

These files are generated from `src/Grammars/hix/HixLexer.g4` and `HixParser.g4` with ANTLR 4.13.2, matching the vendored runtime. Do not edit generated C# files.

From the repository root, regenerate with:

```sh
./gradlew generateHixGrammar
```

The task is registered by the `helix.build` convention plugin and generates both C# and Rider outputs.
