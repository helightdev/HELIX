Compose source generation creates the public authoring API and the retained runtime glue together.
This page explains which generator to choose and what contract each one expects.

## Composition methods

Use <FREntitySymbolLink uid="CompositionAttribute" /> for reusable composition functions. The
method must be static, non-generic, start with `_`, and accept `ref Composition` first.

```csharp
public static partial class AccountViews {
  [Composition]
  private static void _AccountRow(ref Composition cx, string name) {
    using (cx.Row()) {
      cx.Text(name);
      cx.Gap();
      cx.Text("Active");
    }
  }
}

AccountViews.AccountRow(ref cx, player.Name);
```

The generated member is strongly typed. Zero additional parameters produces a
<FREntityCodeLink uid="Composable" />. Additional value parameters produce the matching generic
delegate. A single `in T` parameter produces <FREntityCodeLink uid="ReadComposable-1" />.

## Boundary composables

Use <FREntitySymbolLink uid="BoundaryComposableAttribute" /> for a retained component with its own
recomposition boundary. The target class and every containing type must be `partial`. Generic
boundary composables are not supported.

An optional nested partial `Props` struct defines the generated call surface:

```csharp
[BoundaryComposable(Extension = true, Name = "UserBadge")]
public partial class UserBadge {
  public partial struct Props {
    public string name;
    [Prop(false)] public bool selected;
  }

  protected override void OnRecompose(ref Composition cx) {
    cx.Text(props.name);
  }
}
```

The generator creates:

- `ComposeBoundary`, which creates or reuses the typed boundary node.
- A generated props constructor and equality implementation.
- Props transfer into the retained boundary attachment.
- Stable composition and type IDs.
- An optional `ref Composition` extension method when `Extension = true`.
- A baked composable for a boundary without prop fields.

`Base` selects an open generic boundary base when custom state behavior is needed.
`UseLookupCache` enables the boundary lookup cache before recomposition. `Name` controls the
generated API name.

## Props

<FREntityCodeLink uid="PropAttribute" /> controls generated defaults, equality, and proxy updates.
Its initialization modes are represented by <FREntityCodeLink uid="PropInit" />:

| Mode | Generated behavior |
|---|---|
| `Literal` | Uses the attribute value as the optional parameter default. |
| `Constant` | Uses the supplied string as generated constant syntax. |
| `Deferred` | Accepts nullable input and substitutes generated syntax when the argument is null. |
| `None` | Creates a required parameter with no default. |

Props are equatable by default. Custom `EqualitySyntax` and `HashCodeSyntax` are available when a
prop needs domain-specific comparison. <FREntityCodeLink uid="PropStructAttribute" /> can generate
the same constructor and equality support for a standalone struct.

Read [Prop Structs](/docs/compose/prop-structs) for constructor field ordering, every default mode,
deferred initialization constraints, generated equality and hashing, and common generator errors.

## Context fields on boundaries

Mark a boundary field with <FREntityCodeLink uid="ContextAttribute" /> when it owns a retained
context reference that must be refreshed before every recomposition. The generator emits a `Pull()`
call before the base and user recomposition methods execute.

## Composable proxies

Use <FREntitySymbolLink uid="ComposableProxyAttribute" /> to expose a UI Toolkit class or target
type as a generated Compose method. A class proxy must inherit
<FREntityCodeLink uid="UnityEngine.UIElements.VisualElement" />. A struct proxy selects its target through the `Target`
property.

```csharp
[ComposableProxy(Name = "StatusLabel")]
public partial class StatusLabel : Label {
  [Prop]
  public string Text {
    get => text;
    set => text = value;
  }
}

cx.StatusLabel(text: "Connected");
```

Fields and properties marked with <FREntityCodeLink uid="PropAttribute" /> become generated
arguments. An instance method can participate when every parameter is marked `[Prop]`. The
generator compares incoming values, applies only required updates, yields the retained element, and
runs the configured post-yield behavior.

<FREntityCodeLink uid="ComposableKind" /> determines whether the proxy is a leaf element or opens a
scope for child content. Creation, preparation, pre-yield, post-yield, and scope cleanup syntax can
be customized for framework integrations.

## Choosing the generator

| Need | Use |
|---|---|
| Reusable layout or content delegate | <FREntityCodeLink uid="CompositionAttribute" /> |
| Independent props, state, or reactive subtree | <FREntityCodeLink uid="BoundaryComposableAttribute" /> |
| Native or custom UI Toolkit element in Compose | <FREntityCodeLink uid="ComposableProxyAttribute" /> |
| Reusable generated value object for arguments | <FREntityCodeLink uid="PropStructAttribute" /> |
